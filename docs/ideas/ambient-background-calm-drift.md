# Спокойный «живой» фон (calm drift)

**Дата:** 2026-07-24  
**Статус:** принято → спека [`docs/specs/ambient-background-calm-drift.md`](../specs/ambient-background-calm-drift.md)  
**Контекст ревью:** скриншоты с полосой на фоне teacher-страницы и разметкой «плавать по бокам» на `/login`.

---

## Problem Statement

Как сделать фон приложения **без горизонтальной полосы** и слегка «дышащим» (тихая лава-лампа), чтобы мягкие пятна **медленно плавали слева и справа** от контента и не отвлекали учителя и ученика от форм, таблиц и текста?

**Для кого:** все пользователи UI (учитель и ученик) — один спокойный режим.  
**Когда больно:** длинные страницы (шов посередине/внизу фона); статичный фон на логине выглядит «мертвым», хотя пятна уже есть.  
**Успех:** шов не видно при скролле; на `/login` пятна едва заметно плывут по бокам карточки «Вход».

---

## Что есть сейчас (as-is)

| Слой | Где | Поведение |
|------|-----|-----------|
| `.chem-surface` | `body` в `app/layout.tsx` | `linear-gradient(165deg, band→bg 0%→55%)` без явного `background-size` / `no-repeat` |
| `DecorativeBlobs` global | `layout.tsx`, `fixed inset-0 -z-10` | 4 статичных SVG по углам, opacity ~0.12–0.18 |
| `DecorativeBlobs` scoped | `/login`, student welcome/home/leaderboard, `SessionSummary` | те же SVG, `absolute inset-0 z-0` внутри `relative` родителя |

На части экранов (логин и др.) **одновременно** видны global + scoped слои → риск «двойной лавы» после анимации.

---

## Recommended Direction

**A: бесшовный wash + calm drift текущих SVG в боковых коридорах.**

1. **Шов** — чинить у источника (`.chem-surface` / стык `html`↔`body`), не маскировать зеркальным тайлом. Зеркало — запасной план только если после `no-repeat` + `background-size: 100% 100%` (и при необходимости мягких стопов) шов останется.
2. **Пятна** — не менять технологию (остаются SVG + `--blob-*`). Добавить CSS keyframes: медленно, мало, по бокам.
3. **Коридоры** — левая и правая полосы экрана; центр (карточка max-w-sm, основной контент) без заметного пересечения движущимся пятном.
4. **Интенсивность** — одна, спокойная, на всех ролях и роутах.
5. **a11y** — `prefers-reduced-motion: reduce` → анимация off; `aria-hidden` + `pointer-events-none` сохранить.

---

## Key Assumptions to Validate

- [ ] Полоса связана с фоном `.chem-surface` (или с тем, что фон не покрывает всю высоту документа) — не с другим UI-элементом
- [ ] Drift «еле дышит» и не мешает на Students Hub / списках ДЗ
- [ ] Global + scoped не дают визуально громче/двоения после включения анимации
- [ ] Reduced-motion оставляет ровный статичный фон без шва

---

## MVP Scope

**In**

- Диагностика и устранение горизонтального шва
- 3–4 пятна с тихим drift в боковых зонах
- `prefers-reduced-motion`
- Обновление тестов `DecorativeBlobs` под новые классы/поведение
- Решение по дублю global/scoped минимум на `/login` (см. спеку)

**Out**

- Dual intensity (учитель vs ученик)
- Canvas / turbulence / metaballs / framer-motion
- Замена SVG на blurred `div`-orbs
- Новые цвета бренда / редизайн карточек

---

## Not Doing (and Why)

| Не делаем | Почему |
|-----------|--------|
| Зеркальный тайл как основной фикс | Лечит симптом; шов может вернуться на другой высоте |
| Заметная лава-лампа | Явно запрошено «спокойно везде» |
| Atmosphere по роутам | Лишняя поверхность без выигрыша для MVP |
| JS animation libs | CSS keyframes достаточно и проще для reduced-motion |

---

## Отклонённые альтернативы (idea-refine)

| Вариант | Вердикт |
|---------|---------|
| Только фикс шва, blobs статичные | Не закрывает «пусть плавают» |
| Blur-orbs вместо SVG | Другой visual language; риск «AI background» |
| Dual intensity | Пользователь выбрал спокойный режим **везде** |
| Canvas / liquid | Overkill для кабинета |
