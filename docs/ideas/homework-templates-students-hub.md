# Homework templates + Students hub

**Дата:** 2026-07-23  
**Статус:** idea one-pager (после idea-refine)  
**Связано:** [`docs/specs/teacher-cabinet-ux.md`](../specs/teacher-cabinet-ux.md) (частичное пересечение: вкладки/группы; расхождение: шаблоны ДЗ + accordion вместо drawer)

## Problem Statement

How might we дать репетитору (5–15 учеников, 1–3 группы) собрать ДЗ один раз и в ~3 клика назначать его ученику или группе — без пересборки формы под каждого?

## Recommended Direction

**Template-first, UI-имена без смены бренда.**

- **Задания** — экран создания/списка **шаблонов** (без выбора ученика). Пункт nav остаётся «Задания»; старый flow «сразу к ученику» переделывается в создание шаблона, не живёт вторым путём.
- **Ученики** — операционный хаб с вкладками:
  1. **Добавить** — создать ученика
  2. **Ученики** — таблица read-only (трек, онбординг, баллы); клик по логину → accordion (назначить шаблон, удалить, сброс пароля/invite; история ДЗ / открытые сессии — позже)
  3. **Группы** — CRUD, состав (ученик ∈ 0 или 1 группа), назначить шаблон группе (fan-out per-student assignments)
- Assign создаёт обычные `HomeworkAssignment` со **snapshot** items; правка шаблона не трогает уже выданные.
- **Выход из группы:** несданные ДЗ с этой групповой раздачи **отзываются** (`cancelled`). Сданные / проверенные не трогаем.

Ядро ценности — reuse шаблона. Вкладки и accordion — оболочка под раздачу и админку учеников.

## Key Assumptions to Validate

- [ ] Шаблон без жёсткого трека; при assign к ученику с несовместимым контентом (ЕГЭ→ОГЭ) — блок или предупреждение
- [ ] Items immutable после assign; правка шаблона ≠ изменение выданных
- [ ] Multi-select учеников в одном диалоге assign (не только через группу)
- [ ] Accordion по клику на логин, не drawer и не `/teacher/students/[id]`
- [ ] Revoke-on-leave: статусы `assigned` / `in_progress` → `cancelled`; `submitted` / `reviewed` не трогать
- [ ] AI-диалоги, lightbox/paste, полный chrome-кабинет — вне этой идеи

## MVP Scope

**In**

- Модель/API шаблона ДЗ (`title` + `items`, без `student_id`)
- Переделка `/teacher/homework/new` → создание шаблона (без выбора ученика); список в «Заданиях»
- Assign API: шаблон → 1..N учеников; шаблон → группа (fan-out + provenance группы)
- `/teacher/students`: вкладки Добавить / Ученики / Группы
- Accordion: назначить шаблон, удалить ученика (± сброс пароля)
- Группы: create/edit/состав + assign шаблона
- Revoke несданных при выходе из группы / удалении группы (тот же хук)

**Out (позже)**

- История ДЗ / открытые сессии / AI в accordion
- Paste + lightbox скринов
- Переименование nav «Темы» → «Конструктор» и прочий chrome (отдельные срезы)

## Not Doing (and Why)

- Отдельное имя «Шаблоны» / «Библиотека ДЗ» в nav — привычнее оставить «Задания»
- Dual-run старого «создал = назначил одному» рядом с шаблонами — два способа путают
- Soft-template через клон чужих `HomeworkAssignment` — библиотека смешивается со статусами/сдачами
- Одна Homework-строка на группу без per-student fan-out — нет персонального прогресса
- Drawer / отдельный профиль ученика — выбран expand по логину
- Полный `teacher-cabinet-ux` одним релизом — раздувает scope мимо 3-клик раздачи

## Open Questions

- Точный UX при трек-mismatch шаблона и ученика: жёсткий блок vs confirm с предупреждением (решить в spec).
