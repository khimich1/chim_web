Известная точка: конкурент цитирует **~979 показов/мес** на «репетитор онлайн химия» ([Учитель Рядом](https://xn--d1abinglmnh4b7cvb.xn--p1ai/repetitor-onlayn-himiya)).

### Классы частотности (ниша «химия ЕГЭ»)

| Класс | Показов/мес (ориентир) | Пример |
|-------|------------------------|--------|
| ВЧ | 5 000+ | подготовка к егэ по химии |
| СЧ | 500–5 000 | репетитор по химии егэ, органика егэ |
| НЧ | 50–500 | задача 28 егэ химия разбор |

**Стратегия solo-сайта:** коммерческие СЧ на лендинги + **пачка НЧ/микро** по номерам заданий (long-tail). Не конкурировать с Решу ЕГЭ / Степенin по «тесты егэ химия онлайн» в лоб.

### B. Ученик ищет разбор / теорию (трафик + доверие) — **40% усилий**

| Job | Запросы | Конкуренция | Ваш угол |
|-----|---------|-------------|----------|
| Разобрать задачу | `задача 28 егэ химия`, `задание 28 егэ химия разбор`, `задача 28 примеси` | Высокая (100points, Дзен) | Алгоритм + **ваш пример** + мини-тест |
| Сложная 2 часть | `задача 33 егэ химия`, `задача 34 егэ химия`, `задание 34 егэ растворы` | Высокая | Акцент на **ЕГЭ 2026** (усложнение 33–34) |
| Органика | `органика егэ с нуля`, `органическая химия егэ таблица`, `типы реакций органика егэ` | Средняя | Таблица + связь с заданием 11, 13, 16 |
| Общая химия | `электролиз егэ`, `овр егэ химия`, `гидролиз солей егэ`, `химическое равновесие егэ` | Средняя | Конспект из учебника chim_web |
| Ошибки | `частые ошибки егэ химия`, `типичные ошибки егэ химия` | Средняя | Из практики репетитора |
| Тест | `тест егэ химия онлайн`, `пробный егэ химия` | **Очень высокая** | Только **5 вопросов** lead magnet, не банк |

### C. Не писать (или noindex)

| Запрос | Почему |
|--------|--------|
| `ответы егэ химия`, `решу егэ химия`, `варианты егэ химия с ответами` | Агрегаторы; нулевая конверсия в репетитора |
| `реферат химия`, `доклад химия`, `контрольная химия 9 класс` | Не ЦА |
| `бесплатно курс егэ химия` | Привлекает неплатящих; minus-слова в Директе |
| Полные варианты ФИПИ | Убивает ценность app |
