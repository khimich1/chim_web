# Brand context — chim_web / himych.ru

Контекст для marketing skills (`mkt-*`) и personas (`mkt-*` agents).

**Обновлено:** 29.07.2026

---

## Продукт

| | |
|---|---|
| **Название** | chim_web (бренд: himych.ru) |
| **Суть** | Платформа + репетитор по химии (ЕГЭ/ОГЭ) |
| **Ценность** | Диагностика → пробное → регулярные занятия + ДЗ/тесты в app |
| **Монетизация** | Инд. 2 500 ₽/ч, группа 1 500 ₽/чел × 2 ч |

## Аудитория

| Сегмент | JTBD | Боли |
|---------|------|------|
| **Родители 11-кл** | Найти репетитора, подготовить к ЕГЭ | Страх «не сдаст», непонятно с чего начать |
| **Ученики 10–11 кл** | Подтянуть химию, понять темы | Скучно, непонятно, мало практики |
| **География** | РФ, онлайн | — |

## Каналы (приоритет)

1. **SEO** — Яндекс/Google, «репетитор химия ЕГЭ», тематические статьи
2. **VK Ads** — родители, lookalike, retarget
3. **Telegram** — канал + лид-магнит
4. **Сарафан** — после пробного

## Воронка

```
[SEO / VK / TG] → landing himych.ru/zapis
       ↓
[Форма заявки] → Google Sheet / leads API
       ↓
[Контакт <2ч] → пробное (диагностика бесплатно)
       ↓
[Оплата] → аккаунт в app (noindex)
```

## Tone of voice

- **Язык:** русский
- **Тон:** экспертный, но тёплый; без академического занудства
- **Обращение:** к родителю — «вы»; к ученику — «ты» (на landing — чаще родитель)
- **Избегать:** «лучший репетитор», пустые обещания, давление

## Ключевые сообщения

1. Бесплатная диагностика — узнаете уровень и план за 1 занятие
2. Химия перестаёт быть «чёрной мagic» — объясняю просто, с практикой
3. ДЗ и тесты в app — контроль прогресса без лишней переписки
