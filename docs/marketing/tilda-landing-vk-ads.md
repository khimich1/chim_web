## 1. Архитектура: две страницы, один домен

| Страница | URL (Tilda) | VK Ads креатив | Приоритет |
|----------|-------------|----------------|-----------|
| **A. Диагностика** | `/zapis` или `/ege-himiya` | Креатив A, C | **Старт 15 авг** |
| **B. Группа** | `/gruppa-ege` | Креатив B, E6 | Параллельно с набором |

**Правило:** реклама **не ведёт на главную** — только на dedicated landing с одним CTA.

```
VK Ads → landing A или B → форма / Telegram → CRM Sheet → диагностика → chim_web
```

**App:** `app.ваш-домен.ru` — отдельно, noindex. На Tilda **не ссылаться** на login ученика.

## 2. Общие настройки Tilda (до блоков)

| Параметр | Значение |
|----------|----------|
| Шаблон | Zero Block или готовый «Landing» — **минимум анимаций** |
| Ширина | Стандарт, mobile-first (70%+ VK — телефон) |
| Шрифт | 1 семейство, 16px+ body |
| Цвета | Teal/бирюза (как app) + белый фон + тёмный текст |
| Фavicon | Логотип «Химыч» или инициалы |
| **Title A** | `Репетитор по химии ЕГЭ — бесплатная диагностика \| Химыч` |
| **Title B** | `Группа ЕГЭ химия с 1 сентября — 3 места \| Химыч` |
| **Description** | 140–160 символов с УТП + «диагностика 30 мин бесплатно» |
| Яндекс.Метрика | Счётчик на обе страницы |
| Цели Метрики | `form_submit`, `click_telegram`, `click_phone` |

### UTM (в VK Ads)

```
?utm_source=vk&utm_medium=cpc&utm_campaign=aug2026_diag   → страница A
?utm_source=vk&utm_medium=cpc&utm_campaign=aug2026_group  → страница B
```

**Один экран = одна цель.** Не меню, не блог, не 15 блоков.

### Блок 1 — Hero (Tilda: *Cover* + *Form* или Zero Block)

**Layout:** слева текст, справа форма (desktop); mobile — текст, сразу форма.

**H1 (один, крупный):**
```
Репетитор по химии ЕГЭ и ОГЭ
Бесплатная диагностика 30 минут
```

**Subheadline:**
```
Определим уровень, разберём слабые темы и составим план подготовки.
Онлайн по всей России · 8 лет опыта · личная платформа с ДЗ между уроками
```

**Bullets (3, с иконками):**
- ✓ Индивидуально и группы 4–6 человек  
- ✓ Программа на весь год — не хаотичные темы  
- ✓ Между занятиями: учебник, тесты, домашние задания в одном месте  

**Primary CTA (на форме):**
```
Записаться на диагностику
```
*Под кнопкой мелко:* «Без обязательств · ответим в течение 2 часов»

**Фото:** ваше портретное фото (доверие), не stock. Фон — светлый или размытый класс/химия.

**Форма (минимум полей):**

| Поле | Обязательное |
|------|--------------|
| Имя родителя или ученика | да |
| Telegram или телефон | да |
| Класс (выпадающий: 8–11) | да |
| Цель: ЕГЭ / ОГЭ / школа | да |
| Комментарий | нет |

**Альтернатива под формой:**
```
Или напишите в Telegram: @himich_teacher
```
→ ссылка с целью Метрики `click_telegram`

**Tilda blocks:** `CR01` Cover + Form, или Zero Block 2 колонки.

### Блок 2 — Social proof (Tilda: *Reviews* или *Slider*)

**Заголовок:** `Что говорят родители и ученики`

**Минимум 3 отзыва.** Формат каждого:

```
«[Цитата 2–3 предложения — результат или процесс]»
— [Имя], [11 класс / родитель], [город если ok]
```

*Если отзывов мало — 1–2 реальных + блок «8 лет, N учеников».*

**Цифры (полоска под отзывами):**
```
8+ лет · 100+ учеников · ЕГЭ и ОГЭ · онлайн
```
*Не выдумывать «500+» — только правда.*

**Tilda blocks:** `RE002` Reviews, `TX12` text columns для цифр.

## 4. Landing B — «Группа с 1 сентября»

Отличия от A — **hero и цены**, остальное можно **дублировать** Tilda (shared blocks).

### Hero B

**H1:**
```
Группа подготовки к ЕГЭ по химии
Старт 1 сентября · осталось 3 места
```

**Sub:**
```
4–6 человек · 2 раза в неделю по 2 часа · программа на весь год
1 500 ₽ с человека за занятие + платформа с ДЗ
```

**Bullets:**
- ✓ Дешевле индивидуальных, но не «конвейер» как в больших школах  
- ✓ Одна программа — все идут синхронно, меньше хаоса  
- ✓ Диагностика покажет, подходит ли группа вашему уровню  

**CTA:** `Записаться на диагностику для группы`

**Urgency (честный):** обновлять счётчик мест вручную раз в неделю.

### Блок «Кому подходит группа»

| Подходит | Не подходит |
|----------|-------------|
| 10–11 класс, цель ЕГЭ | Нужен только разовый разбор темы |
| Готов заниматься 2×/нед | Нестабильный график каждую неделю |
| Бюджет важнее 1:1 | Очень слабая база — лучше сначала индив. |

## 5. Соответствие VK Ads → landing

| Креатив VK | Landing | Hero message match |
|------------|---------|-------------------|
| A «Диагностика бесплатно» | A `/zapis` | H1 содержит «диагностика» |
| B «Группа 1 сент» | B `/gruppa-ege` | H1 содержит «группа» + дата |
| C «Родителям» | A + блок FAQ | Первый экран для родителя |

**Message match rule:** первые 3 слова на landing = обещание в рекламе. Иначе bounce ↑, CPL ↑.

## 8. Mobile checklist (VK)

- [ ] Форма видна без scroll на iPhone SE / 13  
- [ ] Кнопка CTA min 48px высота  
- [ ] Телефон/TG — tap-to-call / deep link  
- [ ] Hero текст ≤5 строк до формы  
- [ ] Скрин платформы читаем на 375px  
- [ ] Страница <3 сек на 4G (сжать фото WebP)  

---

## 9. Чего НЕ делать на landing

| Не делать | Почему |
|-----------|--------|
| Многостраничное меню | Уводит с CTA |
| Видео autoplay | Медленно, bounce |
| Pop-up через 5 сек | Раздражает холодный трафик |
| Полный прайс-лист на 20 услуг | Фокус — диагностика |
| Ссылка «войти в кабинет» | Путает родителей |
| Fake «осталось 1 место» timer | Доверие |
| Стена текста про химию | SEO — в блог, не в ads landing |

---

## 10. После публикации

1. Отправить URL в [Вебмастер](https://webmaster.yandex.ru)  
2. Проверить Open Graph (VK preview) — Settings → SEO  
3. 2 тестовые заявки с телефона  
4. В VK Ads указать **final URL** с UTM  
5. Через 7 дней: bounce rate, time on page, G1/G2 в Метрике
