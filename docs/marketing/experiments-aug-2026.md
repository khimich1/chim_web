## E2 — Bundle pitch (5 родителей)

**Когда:** неделя 1 августа  
**Hypothesis:** ≥2/5 согласны на +500 ₽/мес за «платформа + еженедельный отчёт»

### Скрипт (Telegram / созвон, 3 мин)

> [Имя], добрый день! Хочу предложить обновлённый формат подготовки [имя ребёнка].
>
> Как сейчас: занятия + доступ к платформе (учебник, тесты, ДЗ).
>
> **Новый bundle:** занятия + **еженедельный короткий отчёт** мне вам в Telegram (что сделано, где пробелы) + приоритетная проверка ДЗ.
>
> Доплата: **+500 ₽/мес** к текущему формату. Или можем включить в стоимость следующего пакета занятий.
>
> Вам это было бы полезно? Что важнее видеть в отчёте?

**Записывать:** yes / no / negotiate / что попросили в отчёте

**Если 0 yes:** platform остаётся бесплатным; в рекламе: «личная платформа с ДЗ включена»

## E6 — Набор группы (с 1 сентября)

**Когда:** опубликовать **5–11 августа** (за 3 нед до старта)  
**Каналы:** TG, VK, Профi.ру (обновить объявление), Taplink

### Telegram / VK — основной пост

```
📚 Набор в группу подготовки к ЕГЭ по химии — старт 1 сентября

Формат:
• 4–6 человек — не «поток на 50», а мини-группа
• 2 раза в неделю по 2 часа (расписание согласуем)
• Программа на весь учебный год — не хаотичные темы
• Личная платформа между занятиями: учебник, тесты ЕГЭ, ДЗ, прогресс

Для кого:
• 10–11 класс, цель — уверенная сдача ЕГЭ по химии
• Нужна дисциплина и обратная связь, но индивидуалка не по бюджету

💰 1 500 ₽ с человека за занятие (2 часа)
   Группа 4 чел. = занятие 2 часа, фиксированное расписание

Осталось мест: 3 (из 6)

🎯 С чего начать:
Бесплатная диагностика 30 мин — определим уровень и подойдёт ли группа.
Без обязательств.

👉 Записаться: https://taplink.cc/himich_teacher
   Или напишите в личные сообщения

Ведёт: Роман Алексеевич, 8 лет онлайн-преподавания химии

#ЕГЭ2026 #химия #репетитор #группа
```

### Короткий вариант (VK Ads / stories)

```
Группа ЕГЭ по химии — старт 1 сентября
4–6 человек · 2×2 ч/нед · 1 500 ₽/чел
Платформа с ДЗ между уроками
3 места · Диагностика бесплатно
→ taplink.cc/himich_teacher
```

### Профi.ру — добавить в объявление

> **Набор в мини-группу с 1 сентября** (4–6 чел., 1500 ₽/чел., 2 ч). Программа на год + личная платформа с ДЗ. Бесплатная диагностика 30 мин.

**Success E6:** ≥4 оплативших места до 25 августа

## E1 — VK Ads pilot (15–31 августа)

**Budget:** 20 000 ₽ (~1 400 ₽/день)  
**Landing:** Taplink или Tilda `/zapis`  
**UTM:** `utm_source=vk&utm_medium=cpc&utm_campaign=aug2026_diag`

### Preconditions (до 15 авг)

- [ ] 3+ поста в VK (cross-post из TG)
- [ ] Taplink актуален: цены, фото, описание
- [ ] Таблица лидов готова
- [ ] Ответ на заявки <2ч

### Кампания — настройки

| Параметр | Значение |
|----------|----------|
| Цель | Лиды / переходы на сайт |
| Гео | [Ваш город] + «онлайн по России» — **тест A/B** |
| Возраст | 35–55 (родители) |
| Интересы | ЕГЭ, образование, репетитор, 11 класс |
| Устройства | Все |
| Бюджет | 1 400 ₽/день |

### Креатив A — «Диагностика» (унiversal)

**Заголовок:** Репетитор по химии ЕГЭ — бесплатная диагностика  
**Текст:**
```
8 лет готовлю к ЕГЭ и ОГЭ онлайн.

• Индивидуально и в группах 4–6 человек
• Своя платформа: учебник, тесты, ДЗ между уроками
• Видно, что ребёнок делает между занятиями

Бесплатная диагностика 30 мин — уровень и план подготовки.
Без обязательств.

Запись → [ссылка Taplink]
```
**Изображение:** ваше фото + текст «ЕГЭ химия · диагностика бесплатно» (Canva 1080×1080)

### Креатив B — «Группа сентябрь»

**Заголовок:** Группа ЕГЭ химия — старт 1 сентября, 3 места  
**Текст:**
```
Мини-группа 4–6 человек — не поток на 500.

2 раза в неделю · программа на год · платформа с ДЗ
1 500 ₽/чел за 2-часовое занятие

Осталось 3 места. Диагностика бесплатно.
```
**Изображение:** таблица/схема «группа vs индивидуалка» или календарь «с 1 сент»

### Креатив C — «Родителям» (retarget / отдельная ad set)

**Заголовок:** Ребёнок готовится к ЕГЭ по химии?  
**Текст:**
```
5 вопросов, которые стоит задать репетитору — и как я на них отвечаю.

+ Личная платформа: прогресс между занятий не теряется.

Запишитесь на диагностику 30 мин.
```

### A/B правила

| Period | Action |
|--------|--------|
| Day 1–7 | A vs B, equal budget |
| Day 8 | Pause loser (CPL higher + fewer trials) |
| Day 8–14 | Scale winner +20% budget if CPL <4k |
| Day 15 | Retro: stop / scale / fix landing |

### Метрики E1

| Metric | Target | Fail |
|--------|--------|------|
| Leads | ≥8 | <4 |
| CPL | ≤4 000 ₽ | >6 000 ₽ |
| Probables | ≥2 | 0 |
| Paid | ≥1 | 0 at ≥8 leads |

### Вопросы на диагностике (обязательно)

1. Откуда узнали? → записать в CRM  
2. Что искали? (группа / индив / органика)  
3. Класс, цель, срок
