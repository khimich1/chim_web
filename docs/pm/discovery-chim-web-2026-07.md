# Discovery Plan: chim_web — ниша, монетизация, жизнеспособность

**Дата:** 29.07.2026  
**Product Stage:** existing (продукт построен, бизнес — рост)  
**Discovery Question:** Какой путь масштабирования жизнеспособен при главной проблеме — привлечение учеников (сейчас Профи.ру + сарафан)?

---

## Контекст (от основателя)

| Фактор | Значение |
|--------|----------|
| Опыт | 8 лет онлайн-химия, индивидуально; 2 года — группы |
| Каналы привлечения | Профи.ру + сарафанное радио |
| Главная боль | **Привлечение учеников**, не продукт |
| Активы | Готовые презентации на весь год; рабочая платформа chim_web (ЕГЭ/ОГЭ, учебник, тесты, ДЗ, AI, multi-teacher) |
| Три направления | (1) Вести самому через app (2) Нанимать учителей на свои материалы (3) Формат онлайн-школы |

**Связанные документы:** [product-discovery.md](../strategy/product-discovery.md), [monetization-teacher-network.md](../strategy/monetization-teacher-network.md), [seo-strategy.md](../strategy/seo-strategy.md)

## Шаг 1. Стадия и решения

**Тип discovery:** continuous discovery для **существующего продукта** с непроверенной **go-to-market** моделью.

**Решения, которые должен прояснить discovery:**

1. Стоит ли инвестировать в платформу, если acquisition не решён?
2. Какой из трёх путей — последовательность, а не «или-или»?
3. Какие модели монетизации реалистичны при текущих каналах?
4. Когда (и при каких метриках) нанимать первого учителя?

## Шаг 2. Ниша (краткий разбор)

### Рынок

| Сегмент | Размер / динамика | Роль для chim_web |
|---------|-------------------|-------------------|
| Подготовка к ЕГЭ/ОГЭ по химии | Стабильный спрос (≈130k сдающих ЕГЭ химию/год в РФ) | Ядро ЦА |
| Репетиторство 1:1 | Высокий чек (2 000–4 000 ₽/ч), низкая масштабируемость | Текущая модель |
| Онлайн-школы (Умскул, Фоксфорд, 100ballov) | Массовые курсы 15–40k ₽/год, сильный маркетинг | Конкуренты за **внимание**, не за тот же формат |
| Агрегаторы (Профи.ру, Авито) | Высокая конкуренция, комиссия, «товарный» спрос | Текущий канал, **потолок масштаба** |
| Long-tail SEO («задача 28 ЕГЭ химия») | Низкая конкуренция на конкретные задачи | **Главный рычаг** при наличии своего контента (840+840 заданий, 185 лекций) |

### Ваше отличие от «онлайн-школы»

| Онлайн-школа | chim_web / вы |
|--------------|---------------|
| Курс на 500+ учеников, один методист | Живой репетитор + персональная обратная связь |
| Контент «для всех» | Свой учебник, аудио, проверенная методика 8 лет |
| Маркетинг = основной актив | **Методика + контент + платформа** = актив; маркетинг — gap |
| AI без контроля преподавателя | AI по вашему учебнику, логи для учителя |

**Вывод по нише:** ниша жизнеспособна. Проблема не в «есть ли спрос на химию ЕГЭ», а в **канале привлечения и упаковке**. Профи.ру даёт сделки, но не бренд и не LTV. Платформа усиливает удержание, но **сама по себе учеников не приводит**.

## Шаг 3. Идеи (brainstorm, existing product)

### Топ-10 идей (PM + Designer + Engineer)

| # | Идея | Перспектива | Суть |
|---|------|-------------|------|
| 1 | **Solo + platform bundle** | PM | Занятия как сейчас + app между уроками; цена «премиум за контроль прогресса» |
| 2 | **SEO-воронка «диагностика → пробное → app»** | Engineer | Отдельный SEO-сайт на своём контенте; app noindex |
| 3 | **Сеть учителей на ваших презентациях** | PM | Multi-teacher уже в продукте; комиссия 30–40% с лидов |
| 4 | **Онлайн-школа (единый бренд + прайс)** | PM | Вариант 3 — выше маржа, выше операционка |
| 5 | **Freemium банк тестов** | Engineer | Lead magnet: «решить 5 задач → записаться на разбор ошибок» |
| 6 | **Групповые интенсивы** | PM | Уже ведёте 2 года; упаковать как продукт «мини-группа 4–6 чел» |
| 7 | **Telegram + контент-маркeting** | Designer | Канал с разборами задач → доверие → заявка (дешевле Директа) |
| 8 | **Кабинет родителя / отчёты** | Designer | Родитель платит за прозрачность (Профи.ру это не даёт) |
| 9 | **Партнёрство со школами / классный час** | PM | B2B: пакет для класса — долгий цикл, но стабильный |
| 10 | **Уход с Профи.ру на свой бренд** | PM | Постепенно: SEO + сарафан + «найден на сайте» вместо комиссии агрегатору |

### Топ-5 для stress-test (включая ваши 3 варианта)

| # | Идея | Почему в фокусе |
|---|------|-----------------|
| **A** | Solo + platform (ваш вариант 1) | Нулевой риск, ценность **сегодня**, повышает LTV текущих учеников |
| **B** | SEO + лиды (не отдельный вариант, но **must-have** для 2 и 3) | Без этого варианты 2–3 не масштабируются |
| **C** | Сеть учителей (ваш вариант 2) | Презентации на год = moat; multi-teacher готов |
| **D** | Онлайн-школа (ваш вариант 3) | Эволюция C при 5+ учителях и стабильном потоке |
| **E** | Групповые интенсивы | Уже работает; быстрее масштаб выручки/час |

## Шаг 4. Assumptions (мастер-список)

| # | Assumption | Категия | Impact | Uncertainty | Приоритет |
|---|------------|---------|--------|-------------|-----------|
| A1 | Платформа между занятиями **повышает retention** (ученик остаётся 6+ мес vs 3) | Value | Высокий | Средний | **P1** |
| A2 | Родители **готовы платить +10–20%** за bundle «занятия + app + отчёты» | Value | Высокий | Высокий | **P1** |
| A3 | SEO даст **≥5 заявок/мес** за 4–6 мес при 15–20 статьях | GTM | Критический | Высокий | **P0** |
| A4 | Профi.ру **не масштабируется** выше текущего потолка без роста ставки/рейтинга | GTM | Высокий | Низкий | P2 |
| A5 | Нанятый учитель **даст качество ≥80%** вашего уровня по готовым презентациям | Value | Критический | Высокий | **P1** |
| A6 | При 15+ заявках/мес **маржа 30–35%** с учителей окупает операционку | Viability | Высокий | Средний | P1 |
| A7 | Формат «онлайн-школа» **не cannibalize** премиум 1:1 (разные сегменты) | Viability | Средний | Средний | P2 |
| A8 | CAC платной рекламы **15–30k ₽** — окупается при LTV 45k+ | GTM | Высокий | Высокий | P2 |
| A9 | Конкуренты (Умскул) **не блокируют** long-tail SEO по задачам | Feasibility | Средний | Низкий | P3 |
| A10 | Один человек может **70% преподавание / 20% маркетинг / 10% продукт** | Team | Высокий | Средний | P1 |

**Leap of faith (P0–P1):** A3 (SEO лиды), A1 (retention через app), A5 (качество учителей), A2 (готовность платить за bundle).

## Шаг 5. Монетизация — варианты и жизнеспособность

### Сводная таблица

| Модель | Жизнеспособность | Горизонт | Зависимость от acquisition |
|--------|------------------|----------|----------------------------|
| **1. Solo + app (ваш вариант 1)** | ✅ **Высокая** | Сейчас | Низкая — усиливает текущих |
| **2. Занятия + SEO** | ✅ **Высокая** | 3–9 мес | **Решает главную проблему** |
| **3. Bundle «платформа включена»** | ⚠️ Средняя | 1–3 мес | Нужен pitch родителю |
| **4. Группы / интенсивы** | ✅ **Высокая** | Сейчас | Сарафан + Профi.ру |
| **5. Freemium тесты → лид** | ⚠️ Средняя | 6+ мес | Нужен SEO-трафик |
| **6. Сеть учителей (вариант 2)** | ⚠️ Средняя | 12–18 мес | **5+ лидов/мес сначала** |
| **7. Онлайн-школа (варiant 3)** | ⚠️ Средняя–низкая short-term | 18–24 мес | Стабильный поток + ops |
| **8. Родительская подподписка** | ❓ Непроверено | 12+ мес | Нужен кабинет родителя |
| **9. Платная реклама (Директ/VK)** | ⚠️ Осторожно | 6–12 мес | CAC 15–30k, бюджет 50k+/мес |

### Рекомендуемая последовательность (не «или-или»)

```
Фаза 0 (сейчас – 3 мес)
  → Вариант 1: все текущие ученики в chim_web
  → Bundle pitch 5–10 родителям
  → Замер retention / ДЗ / streak

Фаза 1 (3 – 9 мес)  ← ГЛАВНЫЙ СТАВКА
  → SEO-сайт + 15 статей + CTA «диагностика»
  → Telegram-канал (3 поста/нед)
  → Цель: 5+ заявок/мес без роста зависимости от Профi.ру

Фаза 2 (9 – 12 мес)
  → Поднять цены 10–15%
  → Групповые наборы как отдельный оффер
  → Пилот Директа 50k ₽ (замер реальный CAC)

Фаза 3 (12 – 18 мес)  ← Вариант 2
  → 1 нанятый учитель, 5–8 ваших лидов
  → KPI: retention, NPS, сдача ДЗ
  → Комиссия 30–35%

Фаза 4 (18+ мес)  ← Вариант 3
  → Единый бренд школы, 3–5 учителей
  → Операционка: онбординг учителей, QA уроков
```

### Экономика (ориентир)

| Сценарий | Доход/мес | Условие |
|----------|-----------|---------|
| Сolo (сейчас) | 120–200k ₽ | 15–20 ч/нед, Профi.ру + сарафан |
| Solo + SEO | +40–80k ₽ | +3–5 учеников/мес с сайта |
| +2 учителя | +50k ₽ маржи | 12 учеников/учитель, 35% |
| Школа 5 учителей | 400–600k ₽ | 15 учеников/учитель, стабильные лиды |

**Главный вывод по жизнеспособности:** проект **жизнеспособен** как solo-бизнес уже сейчас. Масштаб до «школы» жизнеспособен **условно** — при успешном SEO/маркетинге (A3). **Не нанимать учителей до 5+ новых учеников/мес с собственного маркетинга.**

## Шаг 6. Эксперименты валидации

| # | Тестирует | Метод | Success criteria | Effort | Срок |
|---|-----------|-------|------------------|--------|------|
| E1 | A1 — app повышает engagement | 2 нед DAU/WAU у 5 учеников в app vs 5 «контроль» (архив) | WAU ≥50%, ≥2 ДЗ/нед | Низкий | 2 нед |
| E2 | A2 — bundle | Pitch 5 родителям: «+500 ₽/мес за платформу и отчёты» | ≥2 согласны | Низкий | 1 нед |
| E3 | A3 — SEO лиды | Landing + 5 статей long-tail, форма заявки | ≥2 заявки за 8 нед | Средний | 8 нед |
| E4 | A5 — качество учителя | 1 коллега ведёт 2 пробных по вашим слайдам | NPS родителей ≥8/10 | Средний | 4 нед |
| E5 | GTM — Профi.ру потолок | Аудит: заявки/мес, конверсия, комиссия за 6 мес | Понимание ceiling | Низкий | 3 дня |
| E6 | Freemium | 1 страница «5 задач типа 28» + CTA | ≥10% → заявка | Средний | 4 нед |

### Decision framework

| Результат | Действие |
|-----------|----------|
| E3 ≥2 заявки/8 нед | Ускорить SEO, планировать E4 (учитель) на мес 9–12 |
| E3 <1 заявки | Уточнить гео/запросы; добавить Telegram; custdev 5 родителей |
| E2 ≥2 bundle | Включить bundle в прайс для всех новых |
| E2 0 bundle | App = «включено бесплатно» для дифференциации, не upsell |
| E4 провал | Отложить найм; усилить контроль качества / обучение учителей |

## Checkpoint

**Ваши три варианта — не конкурируют, а идут цепочкой:**

1. **Сейчас:** вариант 1 (app для своих занятий) + группы  
2. **После SEO:** вариант 2 (учителя на ваших материалах)  
3. **После доказанного потока:** вариант 3 (онлайн-школа как бренд)

**Главный риск проекта — не технический** (продукт готов), а **GTM**. Инвестиции в найм учителей без канала лидов = сжигание маржи.
